Structured LLM Prompt Pipeline



Project Overview



This project demonstrates how to build structured prompts, extract JSON data, and validate the output using Python.



Features



\- Structured prompt generation

\- JSON extraction from text

\- JSON object validation

\- Detection of missing fields

\- Detection of invalid data types

\- Automated testing



Technologies Used



\- Python

\- JSON

\- Git and GitHub

How to Run



Open PowerShell in the project folder and run:



cd src

python main.py



How to Run Tests



From the "src" folder, run:



python test\_prompt.py

python test\_validator.py



Expected Result



The program generates a structured prompt, validates JSON data, and displays the result.
